# Changelog

## 1.0.0 — Initial public release

- Published under the CALMGR (Calendar Management System) name.
- Full-screen COBOL TUI, JSON batch interface, and authenticated Flask web UI.
- Week/month calendar views, recurring appointments, audit, backup/restore, CSV and iCalendar interchange.
- 80-column CALR01 calendar and CALR02 streamlined fanfold reports with wrapped subjects.
- SQLite persistence and libsodium Argon2id authentication.

This is the first public CALMGR release. Earlier internal development versions used a different project name and version sequence.
